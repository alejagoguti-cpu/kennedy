# Federación Policéntrica — Kennedy

Prototipo exploratorio de masterplan, preparado para GitHub Pages.

## Interacción
- Arrastrar para desplazar.
- Rueda para acercar y alejar.
- Seleccionar nodos y explorar hipótesis espaciales.
- Activar o desactivar relaciones alimentarias, hídricas y comunitarias.
- Comparar tres escenarios **cualitativos**, no cuantificados.

## Marco de revisión académica
En esta etapa los nodos son hipótesis arquitectónicas: abastecimiento, estación hídrica, aula productiva, microcentral logística y centro de circularidad. Corabastos permanece en el sistema. Deben desarrollarse matriz programática de actividades, actores humanos/no humanos, tiempos, adyacencias/accesos y reglas de simulación.

**Advertencia:** no hay cartografía georreferenciada, métricas validadas ni BIM en esta versión. No inferir distancias, capacidades ni impactos.
